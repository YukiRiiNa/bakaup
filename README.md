# 增量文件夹备份工具

一个基于 Python 与 Tkinter 的桌面备份工具。选择源文件夹 A 和备份文件夹 B 后，程序会把新增或修改过的文件复制到 B，并保留原有目录结构。

## 主要功能

- 增量备份：仅复制新增或发生变化的文件，减少重复复制。
- 保留目录结构：源文件夹内的子目录会同步创建到备份目录中。
- 进度显示：备份前统计文件数，执行时显示已处理文件数量和进度条。
- 执行日志：记录备份开始、每个已复制文件、失败文件与最终结果，并附带时间。
- 设置记忆：源文件夹、备份文件夹和定时规则保存到程序目录的 `config.json`，下次启动自动恢复。
- 定时备份：支持两种互斥规则：
  - 每天固定时间执行，例如每天 `23:30`。
  - 每隔指定小时执行，例如每隔 `2` 小时。
- 安全校验：阻止将备份目录设置为源目录本身、其上级目录或其子目录，避免递归备份。

## 工作原理

程序遍历源文件夹 A 中的全部文件，并按相同的相对路径查找备份文件夹 B 中的对应文件。

- B 中没有对应文件时，直接复制。
- 文件大小或修改时间发生变化时，重新复制并覆盖 B 中的旧版本。
- 未变化的文件会跳过，不会重新复制。
- B 中原有但 A 中已删除的文件会保留，因此该工具是增量备份，不是镜像同步。

复制时使用 `shutil.copy2`，会尽可能保留文件的修改时间等元数据。文件判断使用 Python 标准库的浅比较方式，依据文件状态信息判断是否需要复制。

## 环境要求

- Windows、macOS 或 Linux
- Python 3.10 或更高版本
- 无需安装第三方依赖

## 使用方法

1. 在项目目录中运行：

   ```bash
   python backup_app.py
   ```

2. 选择源文件夹 A。
3. 选择备份文件夹 B。
4. 点击“开始增量备份”。
5. 在进度条、状态提示和执行日志中查看备份过程及结果。

## 定时备份

1. 点击主页的“设置”。
2. 选择“每天固定时间”或“每隔指定小时”。
3. 填写时间或间隔小时数并保存。
4. 在主页勾选“启用定时备份”。

程序会显示当前规则和下一次执行时间。定时备份由程序自身处理，因此需要保持本程序运行；关闭程序后，不会在后台继续执行。

## 配置文件

首次保存设置后，程序会在 `backup_app.py` 同目录生成 `config.json`。其中保存了文件夹路径、定时备份开关、定时方式、执行时间和间隔小时数。

示例：

```json
{
  "source": "D:/Documents",
  "destination": "E:/Backups/Documents",
  "schedule_enabled": true,
  "schedule_mode": "daily",
  "schedule_time": "23:30",
  "schedule_interval_hours": "2"
}
```

## 项目结构

```text
.
├── backup_app.py   # 图形界面、备份逻辑、定时任务与日志
├── config.json     # 自动生成的本地设置文件

```

## 注意事项

- 请将备份目录设置在源文件夹之外。
- 备份目录中的额外文件不会被程序删除。
- 间隔备份支持 1 到 500 小时。
